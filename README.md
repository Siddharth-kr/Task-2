# Internship Task 2 – Strict Tech Stack Implementation

## 🛠️ Tech Stack
- **Templating Engine**: Handlebars
- **Bundler**: Vite

## 📂 Project Structure
- `src/templates/` → Handlebars templates
- `src/assets/` → CSS, JS, images
- `dist/` → Compiled output

## 🚀 Setup Instructions
1. Clone this repository
2. Install dependencies
   ```bash
   npm install
   ```
3. Start development server
   ```bash
   npm run dev
   ```
4. Build for production
   ```bash
   npm run build
   ```
5. Preview production build
   ```bash
   npm run preview
   ```

## 📌 Deliverables
- Final compiled HTML (`dist/`)
- Source code with Handlebars + Vite setup
- README.md
